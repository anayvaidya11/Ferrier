# Claims Register

Every claim WyZen makes externally — proof site, deck, application, video, conversation
— gets a row here **before it is made**: the claim, the committed evidence file that
substantiates it, and its honesty label per MASTER_CONTEXT §4.3 (measured / derived /
literature-sourced / extrapolated / simulated / modeled / assumed). A claim with no row
is not made. If the repository and a published claim ever disagree, the repository is
right and the claim comes down (§4.3).
